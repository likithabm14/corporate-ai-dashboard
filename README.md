# Corporate AI Adoption Dashboard

## Run Locally

pip install -r requirements.txt

streamlit run app.py

## Features

- KPI Cards
- AI Adoption Trends
- Industry Analysis
- Country Analysis
- Investment vs Revenue Analytics
- Automated Insights
- Interactive Filters

## Deployment

1. Push to GitHub
2. Open Streamlit Community Cloud
3. Connect GitHub Repository
4. Deploy app.py# corporate-ai-dashboard
